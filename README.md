# Лист персонажа — Темное фэнтези

Мобильный интерактивный лист персонажа. Основная страница — `index.html`. `manifest.json`, `sw.js` и PNG-иконки нужны для установки как PWA и работы офлайн после первого открытия.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в его корень все файлы из архива.
2. Откройте **Settings → Pages**.
3. В качестве источника выберите публикацию из ветки (обычно `main`, папка `/root`) и сохраните настройки.
4. После публикации откройте выданную GitHub Pages ссылку. Для установки используйте меню браузера **«Установить приложение»** или **«Добавить на главный экран»**.

## Сохранение

Данные сохраняются автоматически в хранилище браузера на том устройстве, где открыт чарник. Кнопка «Сохранить» выполняет явное сохранение. Данные браузера не синхронизируются автоматически между устройствами. Очистка данных сайта/браузера может удалить локальное сохранение.

## Проверка предела

Приложение показывает стоимость и шанс смерти, но не бросает виртуальные кубы. После оплаты ОС игрок проводит физическую проверку и сам выбирает «Выжил» или «Погиб».
